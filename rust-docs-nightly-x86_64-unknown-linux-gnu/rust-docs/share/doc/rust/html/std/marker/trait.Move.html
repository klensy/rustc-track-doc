Trait Move 

Source 
pub unsafe auto trait Move { }
🔬This is a nightly-only experimental API. (move_trait #149607)
Expand description

Marks a type as freely movable to another address in memory.

By default, all types are assumed to be Move. Similar to Sized, the syntax T: ?Move can be used to relax this bound for some type T. However, Move bounds are implicitly added in all cases unless explicitly opted out of - notably, in trait definitions and associated types. If the move_trait feature is enabled, these can similarly be opted out of:

#![allow(incomplete_features)]
#![feature(move_trait)]
use std::marker::Move;

trait Foo: ?Move {
    type Bar: ?Move;
}
