Expand description

Defines how execution units access memory regions.

§Safety

Implementations must guarantee that generated views are disjoint.

Implementations must also implement check_launch correctly since it is soundness-critical.

fn check_launch( len: usize, grid: [u32; 3], block: [u32; 3], ) -> Result<(), LaunchError>

🔬This is a nightly-only experimental API. (gpu_offload #131513)

Checks that a kernel using this strategy can be launched with len elements on a grid by block launch configuration.

This is called automatically before the kernel is launched.

§Soundness

This check is soundness-critical. It may only return Ok unconditionally if and only if a launch is valid for arbitrary len, grid and block values. If there is any configuration for which this strategy would produce incorrect results or cause undefined behavior, it must return a LaunchError instead.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
