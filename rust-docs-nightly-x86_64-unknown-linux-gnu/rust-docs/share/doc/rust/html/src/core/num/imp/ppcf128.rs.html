1/// The IBM extended-precision (double-double) floating-point lang item.

3/// Here we define just the lang item, the public-facing type is defined
4/// in core_arch. It transparently wraps this definition.

7/// for the purpose of doc builds, specifically doc builds in the stdarch repo.

10#[unstable(feature = "num_internals", issue = "none")]

12#[derive(Debug, Clone, Copy)]
